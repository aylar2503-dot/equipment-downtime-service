# Курсовой проект: Интеграционный сценарий «Уведомление о простое оборудования»

## Описание проекта
REST API сервис на FastAPI для приёма данных о простое оборудования, их фильтрации на уровне сервиса и отправки уведомлений в чат-бот и систему инцидентов (Jira).

## Стек технологий
- **Язык:** Python 3.13
- **Фреймворк:** FastAPI
- **Валидация данных:** Pydantic
- **Интеграция с Jira:** jira2py
- **Управление зависимостями:** pip, venv
- **Запуск:** Uvicorn
